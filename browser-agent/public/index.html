Privacy & limits
This service uses Browserless to host the remote browser. A browser session can contain your signed-in accounts. Don't share the live link or access key. Avoid entering credentials into the action form. Some websites prohibit automation or may require additional verification.
Session state is held in the running server's memory. If the service restarts or sleeps, you may need to start a new session. Use the close button when finished.
