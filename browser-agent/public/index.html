What this replaces (and what it doesn't)
Lightpanda replaces the hosted browser engine for supported headless workflows. GitHub and Vercel operations should use their APIs, Git integration, or CLI rather than a browser wherever possible.
This does not provide a visible sign-in window or a hosted AI model. For accounts requiring interactive sign-in, use an official API/token or a browser with a visible login flow. Do not enter passwords or session cookies here.
Sessions are temporary and held in memory. Render free services can sleep or restart. Use only sites and accounts you are authorized to access; respect site terms and verification challenges.
